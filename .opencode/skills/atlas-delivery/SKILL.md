# Atlas Delivery Skill

Use this skill when taking a task from implementation to completion.

## Workflow

1. Inspect current git state.
2. Understand the requested outcome.
3. Identify acceptance criteria.
4. Implement or coordinate implementation.
5. Run relevant tests.
6. Run type checking/build checks when applicable.
7. Inspect git diff.
8. Check for accidental changes.
9. Verify acceptance criteria.
10. Report completion and remaining risks.

## Git Safety

Never:
- delete unrelated user work
- overwrite unexplained changes
- commit secrets
- commit credentials
- hide failed tests

Keep changes focused.

## Completion

A task is complete only when the requested outcome has been implemented and verified.

The final report should contain:
- changes
- verification
- important decisions
- known limitations
- remaining risks
