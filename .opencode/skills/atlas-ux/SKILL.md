# Atlas UX Skill

Use this skill when designing or implementing user-facing Digital Atlas interactions.

## Primary Experience

The globe is the primary interface.

Core flows:
- discover a country
- select a country
- inspect its profile
- inspect Internet metrics
- search for a country
- compare countries
- inspect data provenance

## Rules

- Keep the globe as the primary navigation surface.
- Make country information easy to discover.
- Clearly distinguish metric value, unit, year, source, and limitations.
- Support loading, error, and empty states.
- Design for desktop, tablet, and mobile.
- Consider keyboard and touch interaction.
- Avoid decorative UI that competes with the globe or data.
- Prefer clear hierarchy and restrained visual complexity.
